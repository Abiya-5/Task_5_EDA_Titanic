# Task 5 - Exploratory Data Analysis

## Objective
To perform Exploratory Data Analysis on the Titanic dataset and identify patterns, trends, relationships and anomalies.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

# Dataset
Titanic dataset containing passenger information such as age, sex, passenger class, fare and survival status.

# Analysis Performed
- Dataset overview
- Missing value analysis
- Statistical analysis
- Univariate analysis
- Bivariate analysis
- Multivariate analysis
- Correlation analysis
- Outlier analysis
- Skewness analysis
- Feature engineering

## Key Findings
- Female passengers had a higher survival rate than male passengers.
- First-class passengers had better survival rates than lower classes.
- Fare and passenger class showed a relationship.
- Age and fare distributions contained missing values/skewness.
- Family size was explored as an additional feature.
